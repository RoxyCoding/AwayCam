# AwayCam for macOS 仕様

## スコープ

- キーボード・マウス操作が設定秒数ない場合、すべての画面を黒く覆う。
- 操作が再開されたら、最大0.25秒程度で通常画面へ戻す。
- dアニメストアなどの動画サイト、動画プレイヤー、全画面アプリが前面にある間は暗転しない。
- メニューバーから有効/無効の切り替えと設定変更を行える。

## 制約

- カメラ、人物検出、画像表示、有料API、外部サーバーは使用しない。
- 物理ディスプレイの輝度値は変更しない。機種差や復元失敗を避けるため、黒いオーバーレイで「明るさ0相当」にする。
- 動画サイト判定には前面ウィンドウのタイトルを使う。macOSの権限制限でタイトルを取得できない場合でも、全画面表示と動画アプリの判定は機能する。

## 受け入れ条件

1. 設定時間未満では暗転しない。
2. 設定時間以上の無操作で全画面が黒くなる。
3. 暗転中に入力すると解除される。
4. dアニメストアなどの既知の動画サイト、既知の動画アプリ、全画面アプリでは暗転しない。
5. 設定は次回起動時にも保持される。

## 非対象

- システムのスリープ、画面ロック、セキュリティ保護。
- ブラウザ履歴、URL、再生内容の取得。
- 物理モニターの輝度変更。
