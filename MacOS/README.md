# AwayCam for macOS

キーボード・マウス操作が指定秒数ない場合、すべてのディスプレイを黒く覆い、
**明るさ0相当**にするmacOSメニューバーアプリです。カメラや画像は使用しません。

dアニメストア、YouTube、Netflixなどの動画ページ、主要な動画プレイヤー、
全画面アプリが前面にある間は例外として暗転を止めます。

## 必要環境

- macOS 14 Sonoma以降
- Xcode 15以降（Swift 5.9以降）

## ビルド

ターミナルで次を実行します。

```zsh
cd /AwayCamを保存した場所/MacOS
chmod +x build_app.sh
./build_app.sh
```

テスト成功後、`build/AwayCam.app` が作成されます。Finderで「アプリケーション」へ
移動して起動してください。初回起動時にmacOSの確認が出た場合は、
「システム設定」→「プライバシーとセキュリティ」から許可します。

## 使い方

1. メニューバーのディスプレイアイコンをクリックします。
2. 「設定…」を開き、「操作がない時間（秒）」を入力します。
3. 設定時間を超えると画面が黒くなります。キーまたはマウスを操作すると解除されます。

「動画視聴中は暗転しない」は既定で有効です。動画サイトの判定はウィンドウタイトルに
基づくため、初回案内で「画面収録」権限を許可してください。画面映像は取得せず、
ウィンドウ名だけに使用します。許可しない場合でも、動画を全画面にすると例外扱いできます。
権限はメニューバーの「動画判定の権限…」から後で確認できます。

## 安全性

- 物理ディスプレイの輝度設定は変更しません。黒い全画面表示なので、終了や入力で確実に戻ります。
- 画面ロックではありません。セキュリティ機能としては使用しないでください。
- 入力内容、URL、閲覧履歴は取得・保存・送信しません。

## バージョン

`1.0.0` — macOS初版（無操作暗転、動画・全画面例外、メニューバー設定）
